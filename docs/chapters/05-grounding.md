# 5장. 없는 조문을 인용한다: 인용 형식, 거절, 검증

## 문제

4장까지는 검색만 쟀다. 검색이 맞는 조문을 찾아도, 그 조문을 읽고 쓴 **답**이 없는 조문을 인용하거나 근거 없이 답하면 쓸 수 없다. 그래서 검색 결과를 고정하고 답변만 바꿔 가며 세 가지를 쟀다.

- **환각 인용**: 답에 쓴 조문이 준 자료에 없다
- **거절**: 자료에 답이 없는 질문에 답하지 않는다(거절 정확도), 답이 있는 질문은 거절하지 않는다(과잉 거절)
- 인용을 강제해도 **답의 내용이 나빠지지 않는가**(핵심어 포함률)

## 처방 (지시문과 사후 검증만 바꾼다)

모든 설정에 같은 자료를 준다. 4장 R1 상위 5개 조문의 본문(조문마다 앞 3,000자)이고, 문항마다 한 번 검색해 파일로 고정했다. 답변 모델은 로컬 `qwen3.5:4b`(Q4_K_M, temperature 0, 추론 끔)라서 비용은 0원이다.

| | 처방 | 내용 |
|---|---|---|
| A0 | 자유 답변(plain) | 자료와 질문만 준다 |
| A1 | + 인용 형식(cite) | 주장마다 `[법령명 제N조]`를 붙이고, 자료에 있는 조문만 인용하라고 지시한다 |
| A2 | + 거절(refuse) | 자료에 근거가 없거나 개인 사안 판단·투자 조언이면 정해진 거절 문장만 쓰라고 지시한다 |
| A3 | + 코드 검증(verify) | A2 답을 코드로 검사해, 인용이 하나도 없거나 유효한 인용이 하나도 없으면 거절로 바꾼다. LLM은 부르지 않는다 |

### 인용 채점

답에서 "제N조(의M)"과 "별표 N"을 모두 찾아 앞의 법령 이름(정식 명칭, 약칭, "같은 법", 나열)까지 읽고 나눈다.

| 분류 | 뜻 | 환각 인용 |
|---|---|---|
| shown | 자료로 준 조문 | 아니오 |
| mentioned | 자료 본문에 적혀 있는 조문 번호를 옮겨 적음 | 아니오 |
| unseen | 수집한 법령에 있지만 이번 자료에 없음 | 예 |
| nonexistent | 수집한 법령 이름인데 그런 조문이 없음 | 예 |
| outside | 수집하지 않은(또는 없는) 법 이름이고 자료에도 없음 | 예 |
| unresolved | 법령 이름 없이 쓴 조 번호가 자료에 없음 | 예 |

**이 채점은 조문이 자료에 있는지만 본다.** 인용한 조문이 그 주장을 실제로 뒷받침하는지는 보지 않는다. 또 법 이름 없이 쓴 조 번호는 그 번호가 자료에 있기만 하면 맞다고 본다.

### 평가셋

에이전트 세트 258문항(dev 87, test 171)을 새로 만들었다. 조문 찾기 51, 위임 42, 정의 37, 두 조문 32, 시점 48, 답할 수 없는 질문 48이다. 시점 문항은 현행 조문만 색인한 지금은 맞는 자료를 줄 수 없어 따로 센다(7장). 만든 방법과 한계는 [evalset/README.md](../../evalset/README.md).

## 답을 직접 읽어 본 것

자동 채점이 맞는지 보려고 읽었다. 이 뒤로 test를 보고 지시문이나 채점 규칙을 바꾸지 않았다.

**거절한 것과 못 한 것.** 거절 설정에서 답할 수 없는 48문항(dev 15, test 33)의 답을 모두 읽었고, 자동 판정과 모두 같았다(dev 14, test 24 거절). 자유 답변과 인용 형식의 거절 정확도는 **어림값**이다. "자료에는 없습니다. 다만 최고금리는 연 24%입니다"처럼 섞인 답을 거절로 세기도 하고, 에둘러 거절한 답을 놓치기도 한다.

test에서 거절하지 못한 9문항은 두 부류다.

- **수집하지 않은 법을 묻는데 비슷한 조문으로 답함(4)**: 보험설계사 자격, 가상자산사업자 무신고 영업, 전세보증금, 통신판매 청약철회. 예: 가상자산 무신고 영업을 묻자 "형사 처벌을 받을 수 있습니다"라고 하고 무관한 자본시장법 조문 셋을 붙였다. **인용이 모두 자료에 있는 조문이라 환각 인용 검사에는 걸리지 않는다.**
- **개인 사안을 일반론으로 답함(5)**: "친구가 처벌받나" 같은 질문에 조문 설명으로 답했다.

**남은 환각 인용.** 거절 설정의 test 4문항은 이렇다.

| 문항 | 무엇이 틀렸나 |
|---|---|
| a099 | 자료에는 제377조의3이 있는데 "제377조"로 씀(가지번호 빠짐) |
| a145, a197 | 금융소비자보호법을 "금소비자보호법"으로 씀 |
| a161 | 자료에 없는 전자금융거래법 제14조를 씀 |

넷 중 셋은 **있는 조문의 이름을 잘못 옮긴 것**이다. 모델이 법령 이름을 글자로 쓰게 하는 한 남을 수 있다. 6장에서는 조문을 번호(도구 결과의 ID)로 고르게 하고 이름은 코드가 적게 할 수 있다.

**지시문을 그대로 옮긴 거절.** 거절 설정에서 "…요구하면 다른 말 없이 다음 문장만 써라: …"처럼 지시문까지 적은 답이 dev 3개, test 6개 있었다(답할 수 있는 a063 포함). 거절로 세지만 그대로 보여 줄 수 없는 답이다.

**코드 검증이 바꾼 답 하나.** test a196(신용정보의 정의)은 답이 500토큰에서 끊겨 인용을 쓰기 전에 끝났고, 검증이 맞는 답을 거절로 바꿨다.

**틀린 답은 환각 인용이 없어도 있다.** 답이 자료에 있는데 핵심어를 하나도 못 쓴 문항이 dev 10, test 16개다. 정의 문항이 가장 약하다(test 핵심어 포함률 0.348, 조문 찾기는 0.803). 정의 조항(제2조 등)은 길어서 앞 3,000자에서 잘리는 일이 많다.

## 설정 실수: 반복 억제가 켜져 있었다

처음 dev를 쟀을 때 두 문항(a002, a045)의 답에 "금소비자보호법", "금소비보호법" 같은 이름이 나왔다. Ollama의 `qwen3.5:4b`는 기본 설정에 **`presence_penalty 1.5`**(한 번 쓴 토큰을 피하게 하는 값)가 들어 있고, temperature를 0으로 바꿔도 이 값은 남는다. 0으로 고정하고 dev와 test를 다시 돌렸다. 위 표는 모두 다시 잰 값이다.

| dev, 반복 억제 1.5 → 0 | 자유 답변 | + 인용 형식 | + 거절 |
|---|---|---|---|
| 환각 인용이 있는 답 | 0.103 → 0.057 | **0.092 → 0.023** [−0.138, −0.011] | 0.023 → 0.011 |
| 거절 정확도 (n=15) | 0.533 → 0.400 | 0.600 → 0.533 | 1.000 → 0.933 |
| 과잉 거절 | 0.018 → 0.036 | 0.000 → 0.000 | 0.054 → 0.000 |
| 인용 재현율 | 0.143 → 0.152 | 0.527 → 0.571 | **0.589 → 0.679** [+0.009, +0.179] |

구간이 0을 벗어난 것은 굵게 적은 둘(과 자유 답변의 핵심어 포함률 0.573 → 0.655)이다. 나머지는 차이가 불분명하고, 거절 정확도는 오히려 내려갔다. **이름 오타도 줄었을 뿐 사라지지 않았다**(위의 a145, a197). 4장의 질의 재작성(Q1)과 HyDE(Q2)도 같은 모델을 기본값으로 썼으므로 다시 쟀고, 둘 다 기각한다는 결론은 같았다([4장](04-reranking.md#반복-억제를-끄고-다시-잰-값)).

## 고지

`proviso answer ask "<질문>"`은 거절 지시문으로 답하고, 자료에서 확인되지 않은 인용이 있으면 따로 표시하고, 끝에 "법률 자문이 아니다"라는 고지를 코드로 붙인다(모델에게 쓰게 하지 않는다).

## 한계

- **충실도를 재지 않았다.** LLM 판정자와 그것을 보정할 사람 라벨이 없다. 핵심어 포함률은 답이 맞는지의 어림일 뿐이다.
- **정답 조문의 검증은 로컬 모델 하나로 했다.** 답할 수 있는 210문항마다 정답 조문과 검색 상위 조문을 섞은 후보를 gpt-oss(20B, Q4)에게 보여 주고, 읽어야 할 조문을 고르게 했다. 정답 조문을 하나라도 고른 것이 161문항(77%), 전부 고른 것이 115문항이다. 정의(21/37)와 시점(32/48)이 낮고 나머지는 108/125다. 처음에는 조문 앞 3,000자만 보여 줘서 152문항이었고, 정답 조문이 잘렸거나 답을 잘못 읽어 들인 25문항을 핵심어가 있는 쪽을 보여 주고 다시 물었더니 9문항이 더 맞았다. **어긋난 49문항이 모델의 잘못인지 문항의 잘못인지는 아직 사람이 보지 않았다**(무작위 10%와 애매한 문항을 더한 검토 목록 91문항을 만들어 두었다). 답할 수 없는 48문항에는 정답 조문이 없어 이 검증을 하지 않았다.
- 조문을 3,000자에서 잘라, 시점이 아닌 답할 수 있는 162문항 중 34문항에서 정답 조문이 잘리고 14문항은 핵심어까지 빠진다. 6장에서 조문 전체를 읽는 도구로 다룬다.
- 질문이 검색 세트보다 쉽다(질문과 조문의 단어 겹침 중앙값 0.618, 검색 세트 0.500).
- 시점 문항에는 현행 조문을 줬다. 거절 설정도 test 시점 문항의 34%만 거절했고, 나머지는 지금 규정으로 옛날 질문에 답했다. 7장의 문제다.
- 4B 로컬 모델 하나의 결과다. 모델 비교는 9장이다.
